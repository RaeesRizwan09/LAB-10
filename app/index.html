API

How the binding works

One contract between the Python backend and this page.

Request. The search box sends POST /api/research with {"query": "…"}. A shareable GET /api/research?q=… form is also available.

Response. The backend returns a single JSON object with optional blocks: title, summary, stats, cards, table, chart, calculator, picks, warnings, sections, sources and disclaimer.

Rendering. Each block is optional. The frontend shows only what is present, numbers the sections in order, and links every source. Adding a new topic needs no frontend change — only a new corpus entry or a working retrieval source.
